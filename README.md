# FitLife - Interactive Web Elements

## Project Overview
FitLife is a real-world interactive fitness webpage created for Frontend Development Project 3. The project focuses on JavaScript, DOM manipulation and user interaction.

## Requirements Covered
- Interactive buttons
- Dark mode toggle
- Basic user interaction
- Dynamic content update
- JavaScript event handling
- DOM manipulation

## Technologies
- HTML5
- CSS3
- JavaScript

## Folder Structure
```text
Project-3-Interactive-FitLife/
├── index.html
├── pictures/
│   └── fitness.jpg
└── README.md
```

## How to Run
Open `index.html` in any modern web browser.

## Project Purpose
This project demonstrates how JavaScript can make a webpage interactive by responding to user actions and updating the page content dynamically.
